# Project named CueCal

**Context:** The working title `meeting-minder` was crowded. Minder (OpenSSF project + trademark), BridgeMeet (same-space SaaS), ZapMeet (Zapier-adjacent) and CalSentry (Sentry.io confusion) were rejected after a collision check.

**Decision:** Name the project CueCal (repo/package `cuecal`), chosen 2026-09-29. PyPI `cuecal` was free. It is short and means it takes its cue from your messages.

**Consequences:** Repo is `116-Labs/cuecal`.
